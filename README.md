# EV Charging Station with Smart UPI Payment System 🚗🔋

## Project Overview

An IoT-enabled EV charging solution that integrates an Android application, ESP32-based IoT monitoring, EV charging control, and UPI-based digital payment.

## Technologies Used

- Android Studio
- Kotlin
- Jetpack Compose
- ESP32
- IoT
- UPI Payment
- QR Code

## Key Features

- EV charging management through Android app
- UPI-based payment workflow
- QR-code payment integration
- ESP32-based IoT connectivity
- Charging status monitoring

## Project Objective

To develop a smart and user-friendly EV charging system combining mobile application technology, IoT, and digital payments.
